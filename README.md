# MapMyMeds Protocol 📍💊

MapMyMeds connects pharmacy inventory systems to provide real-time visibility across networks. It helps pharmacists source medication, prevent drug shortages, and reduce waste.

## 🚀 Quick Start

```bash
npm install
npm run dev

```

🛠️ Stack
---------

-   **Frontend:** React, Vite, Tailwind CSS

-   **Infrastructure:** Decentralized middleware

-   **Smart Contracts:** Solidity (Foundry)

-   **Hosting:** Vercel
